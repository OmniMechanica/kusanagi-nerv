# MLP-026 — Inference scale-to-zero and cold-start benchmark

**Project:** KUSANAGI NERV  
**Priority:** P2  
**Schedule:** Stretch (unscheduled)  
**Learning/build timebox:** 3–6 h (estimate, not a deadline)  
**Status:** Planned  
**Dependencies:** [MLP-011](MLP-011.md), [MLP-018](MLP-018.md)

## Objective

Characterize the latency-vs-cost tradeoff of serverless inference.

## Implementation steps

- Implement or document a scale-to-zero pattern compatible with the chosen deployment setup.
- Measure warm and cold request latency (or mark conceptual if no deployment path).
- Observe model load time, deployment time and request behavior during wake-up.
- Calculate idle cost savings versus cold-start impact.

## Acceptance criteria

- [ ] Warm/cold latency is measured with reproducible conditions or labelled DESIGN-ONLY.
- [ ] Tradeoff includes cost, SLO and operational complexity.

## Required evidence

TESTED-CPU if live server; otherwise DESIGN-ONLY.

## What to study in parallel

Ray Serve autoscaling, KubeRay and production ML inference guides.

## Interview drill

When is scale-to-zero unsuitable? How would you guarantee p95 latency for cold requests?
