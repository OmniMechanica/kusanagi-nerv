## Python exercise (45 min)

Implement `async def run_bounded(items, worker, *, limit)` in Python 3.12. `items`
is a finite iterable, `worker(item)` is an async operation, and `limit` is an
integer. Return one result per input in input order.

- Raise `ValueError` for `limit < 1` before consuming any input. Empty input with
  a valid limit returns `[]`.
- Process each item once on success. Cap concurrent worker calls at `limit` and
  keep the number of scheduled worker tasks bounded by `limit`, independent of
  input size. The result list may grow with input size.
- On a worker exception, stop taking new work once the failure is observed,
  cancel and await the remaining worker tasks, then propagate the exception.
  On caller cancellation, also cancel and await the remaining tasks, then
  propagate cancellation.

Write tests that force completion out of order and observe peak concurrency.
Exercise the failure and caller cancellation paths and check that workers have
finished cleaning up before the call exits. Use synchronization events for the
race cases so the assertions do not depend on timing sleeps.

## System design exercise (45–60 min)

Design a self-service ML platform that receives a burst of 500 training
submissions from multiple teams on a shared 32-GPU fleet. Jobs can request one
or several GPUs. Users need job status, cancellation, checkpoint recovery and
an API to deploy a successful model version. These are mock inputs. Ask for or
state any additional scale and latency assumptions you need.

- Trace a submission to execution and a completed model to prediction. Explain
  the control and execution plane boundaries, state ownership and fast admission.
- Explain how the platform admits GPU jobs, handles jobs that need several
  devices and serves predictions while training demand spikes.
- Walk through a lost submit response, a worker loss after a checkpoint and
  cancellation while dispatch is in flight. Defend the roles of Ray and Flyte.
- Identify three production risks in the current platform and propose a
  concrete validation or mitigation for each.
