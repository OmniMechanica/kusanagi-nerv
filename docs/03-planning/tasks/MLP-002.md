## Objective

Expose self-service job submission and lookup without blocking on execution.

## Implementation steps

- Define Pydantic `JobSpec`, `ResourceRequest`, `JobAccepted` and `JobView`; validate CPU/GPU/memory/epoch bounds.
- Implement `POST /v1/jobs` returning 202, job ID and Location; implement `GET /v1/jobs/{id}` with 404 behavior.
- Use in-memory repository for now; keep repository dependency injected so DB can replace it.
- Define OpenAPI examples and stable error models; do not run training in the request handler.
- Test valid/invalid specs, 202, 404 and 422 with FastAPI TestClient and its HTTPX2 backend.

## Acceptance criteria

- [x] All implemented APIs have typed request/response schemas and documented status codes.
- [x] Invalid resource and epoch values are rejected; unknown job ID returns 404.
- [x] Endpoint acknowledges admission without performing ML work or waiting for execution; no latency SLO is claimed.
- [x] API contract tests, runtime schema validation and lint checks pass. Static type checking remains the agreed P1 follow-up.

## Implementation and limits

- Pydantic input validation converts into immutable standard-library domain records. The repository protocol is independent of FastAPI/Pydantic; the API injects an adapter per application instance.
- The [API contract](../../01-product/api-contracts.md#implemented-through-mlp-003) records numeric bounds, identifier syntax, defaults and the `ErrorResponse` envelope. This increment documents `202`/`200`/`404`/`422` and the `Location` header; MLP-003 adds durable storage and `503`.
- The fixed local tenant is test-only. Cross-tenant lookup tests override the tenant dependency; production authentication remains MLP-017.
- Storage is in memory and single-process; jobs remain queued without an executor. Idempotency, cancellation, retry execution and durable state are not implemented by this increment.
- Tests use FastAPI TestClient with the locked HTTPX2 backend supported by the installed Starlette version. See the [TestClient documentation](https://starlette.dev/testclient/).
