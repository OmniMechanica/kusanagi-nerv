**Project:** KUSANAGI NERV

## Objective

Create a confident, repeatable presentation of engineering ability and interview readiness.

## Implementation steps

- Practice a 10-minute project demo from API submission through self-service deployment to prediction and recovery evidence; use HTTP directly or the optional SDK.
- Complete a 45-minute Python backend coding exercise; debrief unit tests and mistakes.
- Complete a 45–60 minute design/ML platform panel and score it.
- Prepare STAR stories for DataRobot, OpenVPN and Capgemini with only verifiable facts.
- Polish documentation, clean setup steps and known limitations; do not add new P2 scope.
- Present KubeRay/GPU design evidence even without GPU hardware. Show tenant/metrics extensions only when implemented and tested; otherwise state deferred scope or discuss labelled design-only material. Full Gate C is not a prerequisite.

## Acceptance criteria

- [ ] Demo reliably reproduces using documented commands/environment.
- [ ] Interview score target >=19/24 and no category under 2, with known gaps recorded.
- [ ] Can answer 5 key GPU/Ray/platform failure questions in 3 minutes each.
- [ ] Required KubeRay/GPU design from `MLP-015–016` is reviewable; skipped P1 work remains explicitly deferred and does not count toward full Gate C.
- [ ] Public-facing claims distinguish CPU-tested, GPU-tested, simulated and design-only evidence.

## Required evidence

TESTED-CPU demo plus recorded/mock score and STAR story scripts.

## What to study in parallel

All project docs and your four courses selectively revisited.

## Interview drill

Defend the hardest decision you made; identify one approach you would change at production scale.

## Definition of Done

Pass applicable checks in [Definition of Done](../../06-engineering/definition-of-done.md); log result and evidence in [progress](../progress.md). Do not call design-only work a successful hardware run.
