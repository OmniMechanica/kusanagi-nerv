# MLP-023 — Multi-GPU DDP/FSDP and NCCL experiment

**Project:** KUSANAGI NERV  
**Priority:** P2  
**Schedule:** Stretch (unscheduled)

**Status:** Planned

## Objective

Experience true distributed GPU training and memory/network tradeoffs.

## Implementation steps

- Run DDP with at least two NVIDIA GPUs (or clearly label simulation if impossible).
- Inspect data sharding, gradient synchronization and worker failures.
- Compare FSDP state/memory behavior if capacity and model size justify it.
- Record communication overhead, throughput and performance limitations.

## Acceptance criteria

- [ ] Actual multi-GPU logs show world size, synchronization and result.
- [ ] Memory/throughput numbers include hardware specification and reproducible config.

## Required evidence

TESTED-GPU required to claim actual multi-GPU experience; otherwise DESIGN-ONLY.

## What to study in parallel

Official PyTorch DDP/FSDP/NCCL and Ray Train docs.

## Interview drill

When does NCCL help or constrain scaling? Why can FSDP be slower than DDP?
